Place the licensed font file here (the file name is what globals.css expects):

  AstenScriptBold.woff2  (or AstenScriptBold.ttf)   -> all script headings, names and signatures

Cormorant Garamond (body/formal text) and Amiri (Arabic) load automatically from Google Fonts via next/font.
Until the Asten Script Bold file is added, the site falls back to a system script font.
